{% comment %} The one skeleton every page in this app inherits, directly or otherwise. Nothing extends this file straight off — pages pick a middle layer instead: base.html ├── base_internal.html staff pages behind @login_required └── base_public.html the game and quiz, which strangers and embeds hit What lives here is only what both layers genuinely share: the document shell and a set of custom properties the layers re-point. Anything that holds for staff pages but not the public ones (cards, tables, the site-map back link) belongs in base_internal, not here. Styles are inline rather than a collected stylesheet on purpose. start.sh lets collectstatic fail and still boots — "an unstyled site beats an outage" — and that trade only holds while a missing static pipeline can't take the styling of every page down with it. {% endcomment %} {% block title %}Halcyon Silks{% endblock %} {% block head %}{% endblock %} {% block body %}{% endblock %} {% block scripts %}{% endblock %}
