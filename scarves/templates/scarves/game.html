Embed this game on another site

Drop this into any page — a Shopify theme section, a blog post, anywhere. No iframe, so it inherits the surrounding page's width and flows with the rest of the content. 

<script src="https://unpkg.com/htmx.org@1.9.12"></script>
<div hx-get="{{ embed_origin }}{{ board_url }}?pairs={{ default_pairs }}"
     hx-trigger="load"></div>

If the host page already loads htmx, skip the script tag. Add &family=1 to deal every board from a single color family instead of at random — much harder, and only as good as the recipe/dye color data behind it.
